# Task Manager API

API REST de gestion de tâches développée avec Spring Boot, en cours de montée en version progressive (V1 → V6).

## Stack
- Java 21, Spring Boot 3.x
- Spring Data JPA, PostgreSQL
- Bean Validation

## Fonctionnalités actuelles (V1)
- CRUD complet sur les tâches (create, read, update, delete)
- Gestion d'erreurs centralisée (404, validation)
- Statuts et priorités des tâches
